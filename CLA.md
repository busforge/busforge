## How to sign

The first time you open a pull request, a bot asks you to sign by posting this comment, as a comment
of its own, in the pull request:

```
I have read the CLA Document and I hereby sign the CLA
```

You sign once; it covers your later pull requests too. The signature is recorded with your GitHub
user name and ID, the pull request and the time, on the `cla-signatures` branch of this repository.
